Politique de Confidentialité

Dernière mise à jour : 02 Février 2026

Cette politique de confidentialité s'applique à l'application MON IPPON KUMITE KARATE (ci-après désignée "l'Application").

En résumé : Nous ne collectons, ne stockons, ni ne partageons aucune de vos données personnelles. L'application fonctionne entièrement hors ligne sur votre appareil.

1. Collecte et Utilisation des Données

L'Application ne collecte aucune donnée personnelle identifiable (comme votre nom, adresse e-mail, localisation, etc.).

Toutes les informations que vous saisissez dans l'Application (telles que votre nom pour le PDF, vos choix techniques, etc.) sont traitées uniquement en local sur votre appareil (mémoire vive du téléphone) pour permettre le fonctionnement de l'Application.

Ces données sont utilisées exclusivement pour générer le document PDF demandé par l'utilisateur.

2. Stockage des Données

Nous ne possédons aucun serveur et aucune base de données. Aucune information saisie n'est transmise via Internet vers des serveurs tiers.

Lorsque vous quittez l'Application ou rafraîchissez la page, les données temporaires sont effacées (à l'exception des fichiers PDF que vous avez choisi de sauvegarder manuellement sur votre appareil).

3. Partage des Données

Comme nous ne collectons aucune donnée, nous ne partageons aucune donnée avec des tiers (partenaires publicitaires, analystes, etc.).

4. Permissions Android

L'Application peut demander l'autorisation d'accéder au stockage de votre appareil uniquement pour :

  • Sauvegarder le fichier PDF généré dans votre dossier de téléchargements/documents.
